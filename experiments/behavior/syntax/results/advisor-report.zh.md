# 三步提示依存分析的复现与扩展实验报告
本实验沿用论文的三步解析协议，比较四个模型阶段在冻结推理条件下的表现。结果表明：加入格式规则、标签清单和一个训练集示例后，三个 Tülu 模型的逐词成绩明显提高，但后训练阶段未呈现持续的依存解析提升，完整依存树的生成仍不稳定。

## 1. 复现论文摘要

Matsuda、Ma 与 Asahara（IWPT 2025）的论文《Step-by-step Instructions and a Simple Tabular Output Format Improve the Dependency Parsing Accuracy of LLMs》研究如何让大语言模型准确输出依存结构。其方法在一次回复中依次预测词性（UPOS）、中心词编号（HEAD）和依存关系（DEPREL），并采用简化 CoNLL-U 的 TSV 表格。作者结合任务监督微调，在 17 种语言上评测，并报告多语言微调的跨语言收益。其任务微调后的 Llama-3.1-8B 在 EWT r2.15 上取得 UPOS 98.4、UAS 94.8、LAS 93.1；这些成绩仅作为背景参照。[原论文，表 3](https://aclanthology.org/2025.iwpt-1.2.pdf)

## 2. 实验目的、内容及与论文的区别

本实验考察通用后训练不同阶段的模型，能否直接完成论文的结构化解析任务，以及结果对提示设计的敏感程度。四个官方模型为 Llama-3.1-8B Base，以及 Tülu-3-8B 的 SFT（监督微调）、DPO（偏好优化）、Final/RLVR（含可验证奖励强化学习的最终版）；本次均冻结权重，不再进行解析任务训练。

使用 UD English EWT r2.15：测试集 **2,077 句、25,094 词**；开发集抽取 128 句选提示。输入提供原句及标准分词，不提供测试句的词性或依存答案。每句一次生成三表：Task 1 为词性，Task 2 加入 HEAD，Task 3 加入 DEPREL。统一采用未量化 BF16、贪心解码、8,192 token 总上下文、seed 42；不重试择优。

| 维度 | 原论文 | 本实验 |
| --- | --- | --- |
| 训练与目标 | 解析任务监督微调；开放模型使用 LoRA | 冻结通用模型，比较后训练阶段的输出行为 |
| 数据范围 | 17 语言单语及多语言训练，并扩展跨语言评测 | 仅英语 EWT r2.15 |
| 提示 | 三步解析及简化表格 | P0 沿用作者提示；P3 增加规则、标签清单和一个训练集示例 |
| 评分 | 作者最终表评分及恢复规则 | 同时报严格评分与作者兼容评分 |

因此，本次完成的是**论文方法协议复用与扩展评测**，尚未复现其任务微调成绩；分数差距不能单独归因于模型或实现优劣。

**评分定义：**UPOS 为词性正确率；UAS 为中心词预测正确率；LAS 要求中心词和依存关系同时正确。严格评分固定以全部标准词为分母，只接受唯一合法 ID 与正确词形的对齐，缺失、歧义及非法预测计错，合法部分仍评分。作者兼容指标为 F1，包含行数门禁和恢复规则，可能高于或低于严格分数。下表均含标点，LAS 去除关系子类型。

## 3. 实验结果

### 3.1 原提示 P0 与选优提示 P3

下表单位为 %。Task 1 UPOS 与最终表 UPOS 分列；UAS、LAS 均取 Task 3。作者 F1 按 UPOS / UAS / LAS 排列。

| 提示 | 模型阶段 | 严格 Task 1 UPOS | 严格最终表 UPOS | 严格 UAS | 严格 LAS | 作者最终表 F1（UPOS / UAS / LAS） |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| P0 | Base | 1.31 | 0.66 | 0.12 | 0.03 | 3.46 / 0.93 / 0.57 |
| P0 | SFT | 45.30 | 20.20 | 4.36 | 2.47 | 30.03 / 7.34 / 4.28 |
| P0 | DPO | 19.78 | 17.22 | 5.12 | 2.86 | 18.18 / 5.23 / 3.07 |
| P0 | Final | 27.56 | 20.29 | 5.51 | 3.01 | 26.66 / 8.23 / 4.69 |
| P3 | Base | 0.00 | 0.00 | 0.00 | 0.00 | 15.44 / 9.20 / 5.98 |
| P3 | SFT | 72.61 | 70.47 | 35.79 | 24.09 | 76.44 / 38.89 / 25.65 |
| P3 | DPO | 68.94 | 65.02 | 35.06 | 23.89 | 62.03 / 33.88 / 22.83 |
| P3 | Final | 70.68 | 66.58 | 35.17 | 23.75 | 62.89 / 33.98 / 22.92 |

P0 的依存成绩较低。Base→SFT 的 Task 1 UPOS 增加 43.99 个百分点；SFT→DPO 的 UAS 增加 0.76 点，95% 置信区间为 [0.04, 1.47]，但 LAS 差值区间跨零。DPO→Final 的 UAS、LAS 区间均跨零。

提示选优仅使用 dev128：P0 原提示、P1 增加 TSV 格式规则、P2 再加 17 个词性标签、P3 再加一个固定训练集示例。四模型平均严格 Task 1 UPOS 分别为 **22.35%、36.31%、27.16%、56.17%**，故统一选择 P3，随后冻结提示评测全测试集。P1、P2 未进行全量测试；P3 属于含一个示例的补充实验。

P3 下，SFT 的 Task 1 UPOS、UAS、LAS 相对 P0 分别增加 **27.31、31.43、21.61 个百分点**。DPO、Final 的 LAS 分别增加 21.02、20.74 点。这是整个提示组合的收益，当前实验不能分离示例和格式规则的各自贡献。

P3 中 SFT→DPO 的 Task 1 UPOS 下降 3.67 点（95% 区间 [−4.95, −2.44]）；DPO→Final 回升 1.74 点（[0.95, 2.58]）。两次比较的 UAS、LAS 差值区间均跨零，未观察到持续提升，也不能据此认定模型等效。区间采用按句配对 bootstrap，重采样 10,000 次。

### 3.2 输出完整性与树结构

下表单位为 %，分母均为 2,077 句。完整表要求行数、字段数和 ID/词形对齐完整，不要求标注正确；有效树要求 HEAD 完整合法、单根且无环，也不等于整树预测正确。

| 提示 | 模型阶段 | Task 1 完整表率 | Task 3 完整表率 | 预算截断率 | 有效树率 |
| --- | --- | ---: | ---: | ---: | ---: |
| P0 | Base | 2.12 | 1.20 | 94.08 | 1.01 |
| P0 | SFT | 52.67 | 26.38 | 0.14 | 11.46 |
| P0 | DPO | 19.74 | 11.75 | 0.00 | 4.43 |
| P0 | Final | 30.86 | 19.79 | 0.00 | 4.09 |
| P3 | Base | 0.00 | 0.00 | 100.00 | 0.00 |
| P3 | SFT | 27.15 | 19.79 | 0.05 | 9.58 |
| P3 | DPO | 33.46 | 21.09 | 0.00 | 6.88 |
| P3 | Final | 38.52 | 24.41 | 0.00 | 6.60 |

P3 提高逐词成绩，但完整表和有效树比例并未同步改善。例如 SFT 的有效树率从 11.46% 降至 9.58%；P3 三个 Tülu 阶段分别有 819、898、912 句含环。结构错误只诊断，不修复，也不全句否决逐词成绩。

**Base P3 的零分主要反映输出失败。**其全部句子耗尽预算，反复输出提示、示例及任务表，重复任务标记造成解析歧义。严格口径不从中挑选答案；作者口径提取部分预测后得到非零 F1。零分不能直接等同于没有句法能力。

## 4. 结论与解释边界

当前证据支持三点：冻结模型的解析表现高度依赖提示；DPO、Final 未在这项任务上带来持续增益；较高逐词成绩仍不能保证可用的完整依存树。

Base 使用作者调用模板，三个 Tülu 模型使用相同的原生模板，故 Base→SFT 同时改变权重与模板，不能视为纯 SFT 因果效应。本实验测量输出行为，不直接证明内部句法表征变化；冻结权重也不能证明未接触过 EWT。若需复现论文成绩，仍须另做对应的解析任务微调及同条件评测。

## 5. 核验与补充资料

八组测试均已完成，每组 2,077 个唯一句子、25,094 个标准词，无基础设施失败；格式失败和截断均保留。表格直接依据逐模型评分，差值由未舍入数据计算。

作者评分在含标点口径下无异常适配；不含标点的两种子类型口径各自记录相同适配句数：P0 SFT/DPO 为 16/1，P3 SFT/DPO/Final 为 7/55/89，其余为 0。异常句以空预测代入作者门禁，未从数据中删除。
